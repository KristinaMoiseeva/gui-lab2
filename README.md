# Лабораторная работа №2 — сигналы и слоты PyQt5

## Задание

Разработать приложение на PyQt5, демонстрирующее механизм **сигналов и слотов**.

В качестве примера используется конвертер валют с тремя связанными значениями:

- доллар (USD);
- рубль (RUB);
- евро (EUR).

При изменении одного значения должны автоматически пересчитываться два остальных.

## Что реализовано

Программа содержит три числовых поля:

- `USD`;
- `RUB`;
- `EUR`.

Можно изменить любое из них. После изменения остальные два поля автоматически пересчитываются.

В работе используются как стандартные сигналы элементов PyQt5, так и собственные сигналы, объявленные через `pyqtSignal`.

Пример пользовательского сигнала:

```python
class RubleSignal(QObject):
    changed = pyqtSignal(float)
```

Стандартный сигнал `valueChanged` передаёт новое значение объекту сигнала:

```python
self.rub.valueChanged.connect(self.ruble_signal.emit_value)
```

Далее пользовательский сигнал подключается к слоту:

```python
self.ruble_signal.changed.connect(self.on_rub_changed)
```

Слот выполняет пересчёт остальных валют:

```python
@pyqtSlot(float)
def on_rub_changed(self, rub_value):
    usd_value = rub_value / USD_TO_RUB
    eur_value = rub_value / EUR_TO_RUB
    self.set_values(usd=usd_value, eur=eur_value)
```

Чтобы программное изменение полей не вызывало бесконечную цепочку сигналов, используется `QSignalBlocker`.

## Курсы

Для демонстрации используются фиксированные коэффициенты:

```text
1 USD = 100 RUB
1 EUR = 110 RUB
```

Курсы в задании не заданы, поэтому они нужны только для демонстрации взаимосвязи элементов через сигналы и слоты.

При необходимости их можно изменить в `main.py`:

```python
USD_TO_RUB = 100.0
EUR_TO_RUB = 110.0
```

## Установка и запуск в Windows

Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и перейдите в папку проекта.

Проверьте, что внутри есть:

```text
cl1.py
cl2.py
main.py
README.md
requirements.txt
```

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запустите приложение:

```powershell
.\.venv\Scripts\python.exe main.py
```

## Проверка работы

После запуска:

1. Измените значение в поле `USD` — `RUB` и `EUR` изменятся автоматически.
2. Измените значение в поле `RUB` — `USD` и `EUR` изменятся автоматически.
3. Измените значение в поле `EUR` — `USD` и `RUB` изменятся автоматически.

Таким образом демонстрируется двустороннее взаимодействие объектов через сигналы и слоты Qt.
